Accessibility statement

We want every prospective partner to be able to use this site.

Last updated 2026-09-08

Wallet Partners LLC aims to conform to the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA. Measures taken on this site include:

  • Semantic HTML with a skip link, landmarks and a logical heading order.
  • Keyboard-operable navigation, filters and forms; visible focus states.
  • Colour contrast at or above 4.5:1 for text; information never conveyed by colour alone (map markers carry numbers; charts include table views).
  • Text alternatives for images; decorative images marked as such.
  • Charts and the station map have accessible names and an equivalent table.
  • No motion that cannot be paused; no auto-playing media.

Known limitations

The interactive map relies on a third-party library (Leaflet); while markers are keyboard-focusable, panning by keyboard may be limited in some browsers. The station directory table below the map provides the same information.

Feedback

If you encounter a barrier, email info@walletpartnersllc.com and we will respond within five business days.
